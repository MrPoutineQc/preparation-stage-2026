---

## Technologies utilisées

* **Éditeur :** Visual Studio Code
* **Langages :** HTML, CSS
* **Framework / outils :** Bootstrap, Bootstrap Icons

---

## Description du projet

### Résumé

Création d’un site thématique d’évaluation et de critique du jeu *Counter-Strike 2*, intégrant la grille et différents composants de Bootstrap ainsi que Bootstrap Icons.

### Objectif du projet

Le mandat de ce travail pratique était d’élaborer un site Web sur une critique choisie par l’étudiant, tout en respectant une structure organisée et responsive à l’aide de la librairie Bootstrap.

### Ma contribution

J’ai conçu la mise en page complète autour de l’univers de *Counter-Strike 2* en exploitant les cartes, conteneurs et barres de navigation de Bootstrap. J’ai ensuite personnalisé les styles CSS afin de créer une identité visuelle adaptée au thème du jeu.
